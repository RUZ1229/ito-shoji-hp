## 二系統の正本

| 系統 | フォルダ | 用途 |
|------|----------|------|
| **社内** | `AI化/千葉配送地図/` | 伊藤商事社内 |
| **他社** | `AI化/千葉配送地図_他社/` | 他社・副社長等（配布先ラベルが違うだけではない） |

## 意図的な差分（現時点）

**許されているのはマーカー凡例の 2t／4t 表示の有無のみ**（`map_overrides.json` の `marker_legend` 等）。

| 項目 | 社内 | 他社 | 備考 |
|------|------|------|------|
| 2t専用（三角） | あり | あり | 現状同一 |
| 4t専用（四角） | **あり** | **なし** | 社内のみ（柏2T+5O 等） |

**ビルド注意** … `_sync_shain_ui_from_tasha()` は **css/js のみ**同期。**index.html と data/ は上書きしない**（9/7 に index まで同期して「共有用」表記・4t 消失の事例あり）。

**オンラインURL** … `live_url_社内.txt` / `live_url_他社.txt`（**合言葉なし**・初回は🔒入力）／ 合言葉は `合言葉.txt` を**別途**渡す

**それ以外**（コース統合・仮想ピン・合言葉・オンラインURL・新機能の片方だけ実装等）は、**社長が明示するまで両方同じ**にする。

## 機能追加の手順（原則）

1. `千葉配送地図_他社/` で実装・確認
2. **同じ変更を** `千葉配送地図/` に反映（または `build_chiba_map_distrib_pack.py` の同期）
3. `build_chiba_map_data.py` … **省略時は両系統**の `map_data.json` を更新
4. zip・オンライン公開 … 配布パック生成 → **自動** `deploy_chiba_map_live`（顧客登録・`--publish-live` 時。省略: `CHIBA_MAP_SKIP_DEPLOY=1`）
5. 社長報告 … **両方更新したか**、**意図的差分を入れたか** を1行で書く

**片方だけ・差分あり** … 社長の明示指示がある場合のみ。

## 地図印刷（2026-09-08）

| 操作 | 動作 |
|------|------|
| ヘッダー「印刷」 | 今の画面（全体・絞り込み後・手動ズーム後）を A4 横で印刷 |
| コース横「印」 | そのコースに絞り込み＋ズーム → 印刷（印刷後もそのコース表示のまま） |
| **工務店1件選択中** | **今の画面のまま全ピン表示**（別コースの周辺店も消さない） |
| **ルート線** | **印刷しない**（`@media print` で `.chiba-route-line { display: none }`） |

**注意** … OSM タイルはネット接続が必要。読込前に印刷すると背景が白くなることがある（1秒ほど待ってから印刷）。帳票フッターに `© OpenStreetMap` を入れている。
