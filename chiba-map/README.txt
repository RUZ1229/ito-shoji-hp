千葉配送地図（社内用）

【初回】
  1) zip を右クリック → 「すべて展開」
  2) 展開されたフォルダを開く（中に index.html がある）
  3) Windows … 開く.bat をダブルクリック
     Mac     … 開く.command
  ※ セキュリティ警告 → 「実行(R)」
  ※ 「千葉配送地図を起動しています...」→ ブラウザが開く
  ※ ダメなとき … 手動で開く.bat（黒い画面を開いたまま）
  ※ 終了: タスクバーの最小化サーバーウィンドウを閉じる（Enter で黒画面を閉じる）

【開く】
  Windows … 開く.bat
  Mac     … 開く.command

【更新】社長から 更新.zip を受け取ったら、このフォルダに置いて
  Windows … 更新.bat
  Mac     … 更新.command
